# COS CON landing page

A one-page site with four link buttons. Plain HTML and CSS, no build step, no JavaScript.

## Files

- `index.html` - the page and the four links
- `style.css` - the look (mobile first, bigger screens at 720px and up)
- `README.md` - this file

## Test it on your computer

1. Open the `cos-con-landing` folder.
2. Double-click `index.html`. It opens in your browser.
3. The four buttons open their sites in a new tab. You need internet for those links only.

## Put it online for free with GitHub Pages

You need a free GitHub account: https://github.com/signup

1. Go to https://github.com/new and create a new repository.
   - Name it something like `cos-con`.
   - Choose **Public**.
   - Do not add a README or license (the folder already has one).
   - Click **Create repository**.
2. On the new repository page, click **uploading an existing file**.
3. Drag these three files into the box: `index.html`, `style.css`, `README.md`.
4. Click **Commit changes**.
5. Click **Settings** (top of the repository page), then **Pages** (left menu).
6. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
7. Set **Branch** to **main** and folder to **/ (root)**, then click **Save**.
8. Wait 1 to 2 minutes, then refresh the Pages settings page. It shows your live address, usually `https://<your-username>.github.io/cos-con/`.

To change something later: open the file on GitHub, click the pencil icon, edit, then click **Commit changes**. The site updates in a minute or two.
